Engineering Architecture

End-to-End Data Pipeline

How requests flow seamlessly from client interactions to asynchronous Gemini AI inference and persistent relational storage.

1. React 19 Client

Vite + Tailwind v4 with client state, optimistic UI & local storage caching.

2. Auth & Route Guards

JWT tokens with passlib bcrypt verification and role protection.

3. FastAPI Router

Pydantic v2 validation, CORS middleware & async endpoint execution.

4. Gemini AI Engine

Prompt engineering with STAR methodology & structured schema output.

5. PostgreSQL / SQLite

SQLAlchemy ORM with 15+ models, cascades & relational integrity.

Developer Runbook

Essential CLI commands to boot and test both services locally.

Local Dev Environment
1. Run Backend Server (FastAPI) 
# Navigate to backend
cd CareerWizard-AI/backend

# Activate virtual environment
.\venv\Scripts\activate

# Start Uvicorn Server
uvicorn app.main:app --reload

# API: http://127.0.0.1:8000
# Docs: http://127.0.0.1:8000/docs
2. Run Frontend Client (Vite) 
# Navigate to frontend
cd CareerWizard-AI/frontend

# Start Vite Dev Server
npm run dev

# App: http://localhost:5173
# Production Build: npm run build
